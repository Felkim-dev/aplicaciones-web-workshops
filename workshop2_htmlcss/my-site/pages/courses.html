List of Courses:

  1. Machine Learning

    Instructor: Juan Pablo Astudillo

    • Main topics: supervised and unsupervised learning, neural networks, model evaluation and validation, feature engineering.

    What I Expect to learn:

    1. How to train and evaluate classification and regression models
    2. The mathematical foundations behind gradient descent and neural networks
    3. How to apply machine learning techniques to real-world datasets

  2. Theory of Computation

    Instructor: Israel Pineda

    • Main topics: automata theory (finite automata, pushdown automata, Turing machines), computability, decidability, computational complexity (P vs. NP).

    What I Expect to learn:

    1. How to design and analyze finite automata and Turing machines
    2. How to prove whether a problem is decidable or undecidable
    3. The fundamentals of computational complexity theory
    4. External link: Introduction to the Theory of Computation

  3. Web Applications

    Instructor: Francisco Hidrobo

    • Main topics: semantic HTML, CSS styling, client-side scripting with JavaScript, the client-server model, HTTP.

    What I Expect to learn:

    1. how to structure semantic and accessible HTML pages
    2. how the client-server model and HTTP requests work
    3. how to build and style responsive, interactive web pages

  4. Scientific Communication Workshop

    Instructor: Andrés Tirado

    • Main topics: scientific writing structure (abstract, introduction, methods, results, discussion), oral presentation skills, peer review, the academic publishing process.

    What I Expect to learn:

    1. how to write a clear, well-structured scientific paper
    2. how to present research findings effectively to different audiences
    3. how the peer-review and publication process works

  5. Image Processing

    Instructor: Gabriela Cajamarca

    • Main topics: digital image fundamentals (pixels, color spaces), filtering and convolution, edge detection, image segmentation, geometric transformations.

    What I Expect to learn:

    1. how digital images are represented and manipulated at the pixel level
    2. how filtering and convolution techniques enhance or extract features from images
    3. how to implement segmentation and edge-detection algorithms

  6. Intelligent Agents

    Instructor: Tito Armas

    • Main topics: agent architectures, search algorithms, planning, reinforcement learning basics, multi-agent systems.

    What I Expect to learn:

    1. how to design rational agents that perceive and act in an environment
    2. how search and planning algorithms solve decision-making problems
    3. the basics of reinforcement learning for training agents
