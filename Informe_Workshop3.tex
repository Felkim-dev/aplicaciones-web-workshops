\section{Introduction}

This report describes the implementation of \textbf{AstroTours}, an interactive landing
page for a fictional space-tourism company, built for Workshop 3 of the Web Applications
course. The page is structured in HTML5, styled with CSS3 (Flexbox-based layout, hover
effects and media queries for responsiveness), and made interactive with jQuery (DOM
manipulation, an image-gallery modal, and client-side form validation).

\section{Project Structure}

The project follows the required file structure:

\begin{lstlisting}[language=bash, caption={Project structure}]
TeneSteve_QuilumbangoFelipe/
|-- index.html
|-- style.css
|-- script.js
\end{lstlisting}

The latest jQuery version (4.0.0) is linked via CDN in \texttt{index.html}, right before
\texttt{script.js}, so that \texttt{\$} is already available when our own script runs.

\section{Implementation}

\subsection{HTML structure}

The page is built as a single-page layout with four main blocks. A \texttt{<nav>}
holds the site brand and a link list with more than the required three navigation
links (Home, Destinations, Gallery, Booking). A hero \texttt{<section>} presents a
heading, a short description and a call-to-action button. The gallery section
(\texttt{\#gallery}) contains four \texttt{<img>} elements, each with a descriptive
\texttt{alt} attribute, satisfying the "at least four images" requirement; a hidden
\texttt{<div id="image-modal">} sits right after it, holding a close button
(\texttt{<span id="modal-close">}) and an empty \texttt{<img id="modal-img">} that
jQuery fills in dynamically. Finally, the contact form (\texttt{<form
id="contact-form">}) has labeled fields for name, email and message (the last one a
\texttt{<textarea>}), plus a submit button, meeting the "name, email, and a message"
requirement.

\subsection{CSS styling}

Flexbox is used as the main layout tool throughout the page: for the navigation
links, and for the image gallery, which uses \texttt{flex-wrap: wrap} and
\texttt{gap} so images arrange themselves in a row and wrap onto new lines when
they don't fit. Hover effects are applied both to the navigation links and to the
buttons, as required. A \texttt{:hover} rule on the gallery images scales them
slightly (\texttt{transform: scale(1.05)}) with a \texttt{transition} for a smooth
effect. The modal is built with \texttt{position: fixed} covering the full
viewport, a semi-transparent dark background, and \texttt{display: none} by
default -- jQuery toggles it to \texttt{flex} to both show it and center its
content. The contact form uses a column Flexbox layout and consistent input
styling (\texttt{box-sizing: border-box} so padding doesn't overflow the 100\%
width). A media query at \texttt{max-width: 768px} adjusts the gallery image size
and the form width for smaller screens, covering the responsiveness requirement.

\subsection{jQuery interactivity}

Three behaviors were implemented in \texttt{script.js}:

\begin{itemize}
  \item \textbf{Toggle effect}: clicking the hero button changes the page
  background to a randomly generated color.
  \item \textbf{Gallery modal}: clicking any \texttt{.gallery-img} copies its
  \texttt{src}/\texttt{alt} into \texttt{\#modal-img} and reveals the modal; it can
  be closed either with the \texttt{\#modal-close} button or by clicking the dark
  background outside the image (checked with \texttt{e.target === this} so
  clicking the enlarged image itself does not close it).
  \item \textbf{Form validation}: on submit, the default browser submission is
  prevented; name, email and message are checked to be non-empty, and the email is
  checked against a basic regular expression. If any check fails, an explanatory
  \texttt{alert()} is shown and submission stops; if everything is valid, the form
  shows \texttt{"Form submitted successfully!"} as required and resets itself.
\end{itemize}

\section{Challenges Faced}

\begin{itemize}
  \item \textbf{Closing the modal without over-closing it}: the first version of
  the "click outside to close" handler risked closing the modal even when
  clicking the enlarged image itself, since both the overlay and the image are
  inside the same \texttt{\#image-modal} element. This was solved by comparing
  \texttt{e.target} against \texttt{this} inside the click handler, so only a
  direct click on the dark background (not on its children) closes it.
\end{itemize}

\section{Conclusion}

The final page satisfies all the required sections (navigation bar, hero, image
gallery, contact form) and all three jQuery behaviors requested in the assignment
(random background toggle, gallery modal, and form validation with the exact
success message), combining a Flexbox-based layout, hover interactions and
responsive media queries into a single cohesive page.
